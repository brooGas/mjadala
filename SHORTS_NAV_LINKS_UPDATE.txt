IMPORTANT DATABASE STEP FOR EXTERNAL LINKS:
Before deploying, open Supabase Dashboard -> SQL Editor and run MIGRATION_SHORTS_EXTERNAL_LINK.sql once. This adds the optional external_url column. Existing Shorts remain valid with no link.

Then upload/replace the project files in your GitHub repository and let Vercel deploy. Test with one new Short and an https:// link. External destinations open in a new browser tab/window; whether the TikTok app opens depends on the device and its app-link settings.
