Mjadala Creator Business Dashboard access diagnostic update

1. Back up your currently deployed business-directory.js.
2. Replace ONLY business-directory.js with the file in this package.
3. Keep the existing business-integration.js and all other app files unchanged.
4. Deploy the updated file with your normal Mjadala deployment process.
5. Open Explore > Business while signed in to the assigned creator-admin account.

What changed:
- The existing Creator Business Dashboard is still the same dashboard; this does not create a new dashboard.
- The admin permission RPC is now checked with explicit error handling.
- If the RPC errors or returns false, a visible diagnostic message is shown instead of silently hiding the reason.
- Auth-state refresh no longer calls getSession() from inside the auth-state callback.
- Admin controls remain hidden unless the permission RPC explicitly grants access.

No SQL migration is required for this frontend diagnostic update.
