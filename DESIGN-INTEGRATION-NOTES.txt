MJADALA — DESIGN-INTEGRATED V6

The approved v6 design preview has been installed as mjadala-main/index.html, so it is now
the entry page when the static app is served.

The former index.html is preserved as mjadala-main/index-legacy-backup.html.

  design entry page does not yet call them.
- Before deployment, test the visual prototype and preserve this ZIP as a backup. Next stage is
  to merge the required live features and connect the database/backend without losing sound,
